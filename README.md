# Music Player

A basic Android MP3 player.

It can:

- ask permission to read music already on the phone
- find MP3 and other audio files
- search songs
- include or exclude folders
- play, pause, next, previous, and seek

GitHub stores this code and can build the install file. It does not run the phone.

## Download the app

1. Open the **Actions** tab on this repository.
2. Open the latest **Build APK** run.
3. Download the artifact named `music-player-apk`.
4. Unzip it and copy `app-debug.apk` to your Android phone.
5. On the phone, open the file and allow install from this source.

The first build starts automatically after these files are uploaded. It can take about 10 minutes.
